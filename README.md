# ✳ 小小造物室

给孩子的项目式 **Python + C++** 编程工作台：先做作品，再挑战算法练习。

**v0.2 是本地浏览器应用，不是桌面安装包。支持 Windows / macOS；Python 免安装，C++ 需要本机编译器。没有接入 AI，不上传代码。**

## 本次新增

- 5 个创作项目：猜数字、互动故事、电子宠物、C++ 星星图案工坊、双语言积分统计器。
- 8 道原创竞赛入门练习：循环求和、数位和、逢七拍手、质数、最大公因数、数组统计、排序、前缀和。
- 每道算法题同时支持 Python 与 C++17，提供题意、范围、输入输出格式、样例、分层提示和多组自动测试。
- 显示每组测试的输入、期望输出、实际输出与运行异常。采用按空白分隔的文本比较，忽略多余空格和换行，不进行数值误差容忍。
- 每个项目、每种语言分别保存代码、输入、完成记录和 20 个版本快照。旧版猜数字存档会自动读取迁移，旧存档不删除。
- Python 标准库资源改用 `.data` 文件名，减少 IDM 将 `.zip` 请求接管的问题。

题目是按常见竞赛知识点设计的原创练习，**不是历年奥赛真题**。A 组适合刚学循环的孩子；B 组引入因数和数组；C 组为选学拓展，不建议急着刷完。内置测试是学习反馈，不能替代正式竞赛评测。

## Windows 启动

你已安装 Node.js 24，可直接使用。其他电脑先安装 [Node.js 24 LTS](https://nodejs.org/)。

1. GitHub 页面点击 **Code → Download ZIP**，下载并解压。
2. 在解压后的项目文件夹打开 PowerShell，依次执行：

```powershell
npm.cmd ci
npm.cmd run dev -- --open
```

也可双击 `start-windows.bat`。保持命令窗口开启，Ctrl+C 停止。**更新旧版后必须重新执行 `npm.cmd ci`**，安装新增依赖。仅解压或双击 `index.html` 不能启动。

### Windows 安装 C++ 编译器（只需一次）

Python 不需要这一步。如果电脑已有可用的 g++ 或 clang++，先点击软件中的“检查 C++ 环境”。

推荐使用免费的 [MSYS2](https://www.msys2.org/)：

1. 从官网下载安装 MSYS2，建议保留默认目录 `C:\msys64`。
2. 打开开始菜单中的 **MSYS2 UCRT64**，在它的终端中运行：

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc
```

出现确认提示时按回车并等待安装完成。

3. 关闭正在运行的小小造物室服务，重新启动，进入 C++ 项目点击“检查 C++ 环境”。

软件会自动检测 `C:\msys64\ucrt64\bin\g++.exe`，默认目录无需手动配置 PATH。如果安装在其他位置，可在启动软件的 PowerShell 中设置编译器完整路径：

```powershell
$env:CXX = 'D:\msys64\ucrt64\bin\g++.exe'
npm.cmd run dev -- --open
```

`CXX` 只填程序路径，不要加编译参数。不要仅安装 Visual Studio 的 MSVC 编译器：本版本只支持 GCC / Clang 的 C++17 命令行接口。

## Mac 启动（包括 M1 8GB）

1. 从 [Node.js 官网](https://nodejs.org/) 安装 **24 LTS**。M1 芯片选择 macOS ARM64。
2. 下载并解压项目。在终端输入 `cd `（末尾有空格），把项目文件夹拖入终端，按回车。
3. 执行：

```bash
npm ci
npm run dev -- --open
```

以后可运行 `bash start-mac.command`。ZIP 下载后若不能双击脚本，直接使用终端方式，无须关闭系统安全设置。

### Mac 安装 C++ 编译器（只需一次）

在终端执行：

```bash
xcode-select --install
```

按系统提示安装 Apple 命令行工具，无需安装完整 Xcode。完成后执行 `clang++ --version` 确认，再重新启动小小造物室。

## 如何学习

- 点击顶部“项目与题库”选择创作项目或算法练习。
- Python 创作项目使用逐次交互输入；Python 算法题和全部 C++ 内容使用**预先填写的多行输入**，运行时会读完输入并遇到 EOF。
- C++ 当前不提供运行中逐行输入。星星工坊先填一行高度；积分统计器第一行填人数，第二行填积分。
- “运行作品”使用你填写的输入；“提交测试”使用题库内的全部测试数据。
- 算法题不要输出“请输入”等提示文字，输出必须符合题目要求。
- “给我一点提示”逐层展开预设提示；还没有 AI 自动辅导。
- 创作项目的“我来检查一下”是孩子自查；算法题通过内置自动测试后记录完成。完成记录代表曾经通过，修改后的版本仍需重新测试。
- 修改代码不影响已启动的那次运行；测试反馈对应提交时的代码。
- 每次运行或提交前保存快照；版本记录按项目和语言分别保存，恢复前保留当前代码。
- 在相同浏览器、相同本地网址下自动保存；清空浏览器数据、切换浏览器或端口、换电脑不会携带进度。定期导出 `.py` / `.cpp` 备份。
- GitHub 同步软件源码，**不自动同步孩子的作品**。换电脑可导出后用文本编辑器打开，再复制到代码区。
- 不要同时在多个标签页编辑同一个项目。

## 运行边界与安全

Python 运行在浏览器 Worker，无法直接任意读取电脑文件，但不是面向陌生代码的完整安全沙箱。

**C++ 程序以当前用户权限在本机运行，能访问本机文件和网络。请家长只运行自己或检查过的代码，不要粘贴运行来源不明的 C++。** 每次在临时目录编译运行、结束后清理；限制运行时间和输出量，不等于完整系统沙箱，也没有操作系统级的内存、磁盘或网络隔离。

- C++：编译上限 20 秒，每组运行上限 3 秒；编译错误、非零退出、超时、输出过多都会反馈。停止时会尝试结束进程树。
- Python：启动上限 60 秒；交互项目每次计算阶段 60 秒，等待输入不计时；算法题每组计算上限 3 秒。
- 两种语言均限制输出至约 60 KB / 字符级别。停止按钮可取消当前操作。
- 本地 C++ API 只接受回环 Host 与自定义请求头，并校验 Origin；启动服务默认只监听 `127.0.0.1`。不要改成公网或局域网监听。
- 本机服务最多接受两个并行原生编译请求。C++ 启动与编译检查不会上传代码。

## 常见问题

**点击运行弹出 IDM 下载窗口？**

新版已将标准库从 `.zip` 改名为 `.data`。如果 IDM 仍拦截，在 IDM 的站点排除列表加入 `127.0.0.1` 和 `localhost`，或者临时禁用浏览器的 IDM Integration Module 扩展，然后刷新重试。无须手动下载运行资源。

**Python 提示安全运行环境不可用？**

请从启动命令打开 `http://127.0.0.1:5173`（具体端口以终端显示为准），不要打开本地 HTML 文件。推荐最新版 Chrome / Edge；Safari 需要实际设备验证。开发和预览服务器均设置 SharedArrayBuffer 必需的 COOP/COEP 响应头。

**找不到 C++ 编译器？**

查看上方安装说明，安装后重启服务。可用 `g++ --version` 或 `clang++ --version` 检查。软件的“检查 C++ 环境”会给出实际检测结果。

**Python 输入数据用完？**

算法模式的数据只在运行前填写。检查 input() 的调用次数和输入行数；每次 input() 消耗一行。不要把交互菜单程序直接用于算法题。

**更新后页面还是旧版？**

先导出重要作品，停止服务。下载新版本，在新项目文件夹执行 `npm.cmd ci` / `npm ci`，然后启动并刷新浏览器。保持同一浏览器及端口，旧猜数字存档会迁移。

## 开发与验证

```bash
npm ci
npm run build
npx playwright install chromium
npm test
```

测试需要本机 g++ 或 clang++。覆盖旧存档迁移、项目/语言独立保存、真实 Python 多轮与中文输入、C++ 编译运行/报错/停止、输出限制、超时、自动测试正误反馈、全部 8 道题的双语言参考实现、版本恢复与导出。GitHub Actions 在 Windows / macOS / Linux 上运行；Windows CI 安装 MSYS2 GCC。

```bash
npm run build
npm run preview -- --open
```

预览也包含本地 C++ API。**不能仅把 dist 部署到静态网站来提供 C++**；需要 Node.js 本地服务、Vite 插件和编译器。构建不会把 C++ 编译器打包进应用。

## 结构与后续

- `src/catalog.ts`：创作项目、算法题、起始代码、提示和测试数据。
- `src/projects.ts`：原版猜数字教学内容。
- `src/runtime.ts`：Python Worker / C++ 本地 API 调用。
- `server/cpp.ts`：编译器检测、受限时长的编译执行、临时文件清理。
- `public/python-worker.js`：Pyodide 执行与输入桥接。
- React + CodeMirror + TypeScript + Vite，localStorage 保存作品。

安装时下载所需组件，安装后的常规学习可离线运行。暂不支持 pygame、任意第三方 Python 包、AI 辅导、作品云同步和原生桌面打包。下一步优先根据孩子试用反馈调整任务，再增加作品导入与更完整的运行隔离。
